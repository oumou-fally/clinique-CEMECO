# Projet Clinique CEMECO

## Description

Application de gestion des services d'une clinique (patients, rendez-vous, médecins, secrétaires).

## Technologies

* Node.js / Express
* MySQL
* React (si tu en as)

## Installation

1. Cloner le projet :
   git clone https://github.com/oumou-fally/clinique-CEMECO.git

2. Installer les dépendances :
   npm install

3. Importer la base de données :

* Ouvrir phpMyAdmin
* Importer le fichier : database/clinique.sql

4. Lancer le serveur :
   npm start

## Fonctionnalités

* Gestion des patients
* Gestion des rendez-vous
* Planning des médecins
* Notifications (si tu as commencé)
